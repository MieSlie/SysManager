# Схема управления ПК в локальной сети
Flask-приложение с веб-интерфейсом в виде сетки блоков, каждый из которых соответствует отдельному ПК в сети. Пользователь может выбирать один или несколько блоков, а затем выполнять для них массовые действия - подключаться по SSH/RDP, выключать ПК или отправлять команды.

Цель проекта - Упростить и ускорить администрирование парка ПК в локальной сети. Дать администратору единый визуальный интерфейс, где можно выбрать несколько ПК сразу и выполнить для них массовое действие.

## Ключевые функции
- Сетка блоков - ПК расположены на схеме в соответствии с их реальным размещением в аудитории.
- Множественный выбор - клик по блоку выделяет его, повторный клик снимает выделение.
- Всплывающее меню - при наведении на блок появляется контекстное меню с действиями:
  - Подключение по SSH
  - Подключение по RDP
  - Выключение (с подтверждением)
- Панель действий - появляется внизу экрана при выборе хотя бы одного блока:
  - Кнопка «Выбрать всё»
  - Кнопка «Очистить выбор»
  - Поле ввода команды и кнопка «Выполнить действие»

## Технологии
- **Backend:** `Python 3`, `Flask`.
- **Frontend:** `HTML5`, `Tailwind CSS`, `Vanilla JS`.
